# UDP Core ADRs

Architectural Decision Records (ADRs) for the UDP core package live in this
folder.

These ADRs are owned by `udp-core` and remain with the package if it is
extracted into a standalone repository. Repository-wide, multi-package, and
inter-package decisions are recorded in the root [ADR collection](../../../../docs/adrs/README.md).
