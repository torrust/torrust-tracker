What is verified and what is not:

- Verified: the script runs under systemd; its restart branch works on the real runner when forced; the unit fails only through the script's exit status.
- Not verified: the restart triggered by the real 70% threshold under systemd, and three consecutive scheduled runs. The failure exit at 85% was tested only with stubs, not on the runner.
- The trigger that leaves orphaned build state in dockerd is still unproven (see the issue). The cache can pin itself again; the early warning is the same pattern as before: a prune that frees 0 B while the cache is far above 120 GiB (128.8 GB).
