# Test Design Review

## Schema Root

### Arrange

The canonical strict issue and EPIC Rust types define the v1 contract.

### Act

Generate the JSON Schema root and serialize it as JSON.

### Assert

The root declares Draft 2020-12, contains exactly the strict profiles, preserves the fixed version,
experimental-field allowance, and the approved reference patterns.

### Review

The test keeps the canonical model as the only causal input and asserts contract-visible output.
The retained AAA comments state irreducible context; no helper hides generation or expected schema
properties.

## Drift Check

### Arrange

A disposable schema artifact differs from the deterministic generated bytes.

### Act

Compare the copy with the canonical generated schema.

### Assert

The command reports drift and names regeneration; separate deterministic serialization coverage
proves repeated generations produce identical newline-terminated bytes.

### Review

The temporary artifact owns only file mechanics. The production comparison and independently
specified failure message remain visible. The explicit-artifact test isolates the one new command
argument behavior: it chooses the requested copy instead of the tracked artifact.
